**Для парсинга информации об отключениях воды, электричества, света, отопления и газа используется открытая база с сайта:** https://otklyuchenia.ru/

**Для парсинга данных Управляющих компаний используются открытые выгрузки ГИС ЖКХ:** https://dom.gosuslugi.ru/

# Домовой

Сервис для жильцов: предупреждает об отключениях воды и электричества и передаёт
обращения в управляющую компанию. Бот работает в мессенджере MAX, то же самое
доступно на сайте.

Проект хакатона, трек «Умный город».

## Что умеет

- собирает отключения с сайта поставщика услуг по расписанию;
- присылает жильцу сообщение, когда отключение касается его дома;
- принимает обращение (тема, текст, фото) и отправляет его письмом в УК;
- показывает отключения по городу и по конкретному адресу на сайте;
- даёт управляющей компании панель со списком обращений и статусами.

## Стек

Python 3.12, FastAPI, SQLAlchemy, SQLite или PostgreSQL, HTML + CSS + JavaScript
без сборщика. Бот — прямые запросы к MAX Bot API.

## Быстрый старт

```bash
git clone <адрес репозитория>
cd domovoy

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # Windows: copy .env.example .env
python -m app.seed               # справочник УК и демо-отключения
uvicorn app.main:app --reload
```

Откройте:

- http://localhost:8000 — сайт, проверка адреса
- http://localhost:8000/appeal — форма обращения
- http://localhost:8000/admin — панель УК (токен из `ADMIN_TOKEN` в `.env`)
- http://localhost:8000/docs — документация API

В демо-данных есть адреса, по которым точно есть отключения: **улица Ленина, 11**
и **улица Мира, 12к2**.

Письма по умолчанию никуда не уходят: при `SMTP_DRY_RUN=true` они складываются
в папку `outbox/` в формате `.eml`. Открываются любым почтовым клиентом.

## Бот в MAX

1. Получите токен: `business.max.ru` → верификация профиля → «Чат-боты» → создать бота →
   модерация → «Интеграция» → «Получить токен». Верификация занимает до 48 часов,
   модерация бота — до 24 часов, поэтому начинайте с этого шага.
2. Впишите токен в `.env` (`MAX_BOT_TOKEN`).
3. Запустите бота рядом с работающим API:

```bash
python -m app.bot.main
```

Если бот не стартует с ошибкой авторизации, проверьте `MAX_API_BASE_URL`
(по умолчанию `https://platform-api.max.ru`, запасной вариант `https://botapi.max.ru`) и
`MAX_AUTH_MODE` (`header` или `query`). Актуальные значения — в документации
на dev.max.ru.

## Парсер

Шаблон в `app/parser/site.py` рассчитан на таблицу вида «ресурс / адреса / начало /
конец / причина». Под свой источник меняете три вещи в начале файла:

```python
ROW_SELECTOR = "table.outages tr"                  # селектор строки
COLUMNS = {"utility": 0, "addresses": 1, ...}      # номера колонок
DATE_FORMATS = ("%d.%m.%Y %H:%M", ...)             # форматы дат
```

Запуск:

```bash
python -m app.parser.runner --once   # один проход, удобно при отладке
python -m app.parser.runner          # по расписанию
```

Адрес источника — в `PARSER_SOURCE_URL`.

## Парсер УК из ГИС ЖКХ

Справочник управляющих компаний и их домов собирается из двух открытых
выгрузок [dom.gosuslugi.ru](https://dom.gosuslugi.ru/):

- **реестр поставщиков информации** — xlsx с названием, ОГРН, email, телефоном
  и сайтом организаций;
- **сведения об объектах жилищного фонда** — архив с адресами домов, способом
  управления и ОГРН управляющей организации.

Дома сопоставляются с организациями по ОГРН, поэтому у каждой компании в
справочнике есть её телефон, почта и сайт, а обращение уходит нужной УК.

```bash
# скачать выгрузки, собрать справочник города и записать csv + json
python -m app.parser --city Новосибирск --out data/nsk

# то же самое и сразу загрузить в базу
python -m app.parser --city Новосибирск --out data/nsk --load

# загрузить в базу готовый файл
python -m app.parser --load data/nsk/novosibirsk.json
```

Файлы выгрузок складываются в `parser_cache/` (по умолчанию) и повторно не
качаются. Выгрузка объектов жилищного фонда весит около 3 ГБ: она скачивается
кусками параллельно, а на диск попадает только разжатый csv нужного региона,
поэтому полный архив остаётся на сайте. Парсер берёт только многоквартирные
дома, которыми управляет организация, и только нужный город.

Формат csv повторяет `data/companies.csv`, поэтому его читает и `app.seed`.
Повторная загрузка не создаёт дублей: компания ищется по паре «название + город»,
дом — по компании, городу, улице, номеру и корпусу.

## Демо-данные

```bash
python -m app.seed             # УК + отключения
python -m app.seed --companies # только справочник УК
python -m app.seed --clear     # очистить отключения и отметки об уведомлениях
```

Перед защитой сделайте `--clear`, а затем `python -m app.seed` — бот разошлёт
уведомления заново, в том числе на ваши собственные адреса.

Парсить сайты поставщиков пока нельзя, поэтому демо-данные собраны для
Новосибирска: справочник `data/companies.csv` — 6 УК, 85 улиц, 2190 домов. Демо-отключение
создаётся автоматически на каждую улицу справочника, время и причина выбираются
стабильно по названию улицы. Отключения заводятся относительно текущего момента,
повторный `app.seed` дубли не создаёт.

Справочник УК лежит в `data/companies.csv`. Собрать настоящий по своему городу
можно парсером из раздела выше; формат тот же: колонки
`name, email, phone, website, city, street, houses`, дома перечисляются через
запятую, диапазон пишется через дефис. Одна строка — одна улица; корпус
добавляется как отдельный дом, например `12к2`.

## Всё через Docker

```bash
cp .env.example .env
docker compose up --build
docker compose exec api python -m app.seed
```

Поднимутся четыре сервиса: `db`, `api`, `bot`, `parser`.

## Тесты

```bash
python -m unittest discover -s tests -t .
```

Покрыт разбор адресов — самая хрупкая часть: если житель и источник напишут один
дом по-разному, уведомление не дойдёт. Отдельно проверяется парсер ГИС ЖКХ:
разбор xlsx, адресов домов, склейка с УК по ОГРН, выгрузка и повторная загрузка
без дублей.

## Структура

```
app/
  main.py            FastAPI: роутеры, статика, /docs
  models.py          таблицы: пользователи, адреса, УК, отключения, обращения
  schemas.py         схемы запросов и ответов
  config.py          настройки из .env
  routers/           users, outages, appeals, companies
  services/
    addresses.py     нормализация адресов и разбор строк источника
    matching.py      кого затрагивает отключение, какая УК у дома
    outages.py       создание отключений с защитой от дублей
    mailer.py        письмо в УК, режим outbox для разработки
    notifier.py      рассылка уведомлений
  parser/
    base.py          базовый парсер: скачать, разобрать, не упасть
    site.py          шаблон под конкретный сайт
    runner.py        разовый запуск и расписание
    downloader.py    скачивание выгрузок dom.gosuslugi.ru
    xlsx.py          потоковый разбор xlsx без внешних библиотек
    companies.py     разбор адресов домов и склейка с УК по ОГРН
    export.py        выгрузка справочника в csv и json
    loader.py        загрузка справочника из csv или json в базу
    __main__.py      python -m app.parser: сборка и загрузка справочника
  bot/
    client.py        клиент MAX Bot API
    api.py           обращения бота к нашему REST API
    handlers.py      сценарии диалогов
    texts.py         все тексты и подписи кнопок
    keyboards.py     клавиатуры
    main.py          long polling и поток рассылки
  seed.py            демо-данные
web/                 сайт: index, appeal, admin, css, js
data/                справочник УК и демо-отключения
docs/                архитектура и визуальный язык
tests/               тесты разбора адресов и парсера ГИС ЖКХ
```

## Что доделать после хакатона

- Приём ответов УК с почты, чтобы статус обращения менялся сам.
