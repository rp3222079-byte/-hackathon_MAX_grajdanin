# Визуальный язык «Домового»

Кому: дизайнеру команды. Это стартовая точка, а не догма — правьте токены в `web/css/styles.css`.

## Откуда взят язык

Предмет — коммунальные сети дома: стояки, щитовая, график работ на двери подъезда.
Отсюда две опоры: **инженерная схема** (вертикальная линия стояка, цветовая маркировка
ресурса) и **объявление на подъезде** (плотный текст, никакой рекламной интонации).

## Токены

Цвет:

| Токен | Значение | Роль |
|---|---|---|
| `--concrete` | `#E9EDEF` | фон страницы, холодный бетон |
| `--paper` | `#FFFFFF` | панели с содержимым |
| `--ink` | `#16212B` | основной текст |
| `--ink-soft` | `#5A6B77` | подписи, вторичное |
| `--water` | `#1F6F8B` | холодная и горячая вода |
| `--power` | `#B8860B` | электричество, латунь вместо неона |
| `--heat` | `#A34A2A` | отопление и газ |
| `--alert` | `#9B2C22` | аварийное отключение |

Шрифт: одна гарнитура — **Golos Text** (Google Fonts, рисовалась под русский текст).
Начертания 400 / 500 / 700. Заголовок крупный и плотный, `letter-spacing: -0.02em`.
Длина строки — до 68 символов.

Сетка: одна колонка, максимум 68rem, всё выключено влево. Никаких центрированных
абзацев: адреса и даты читаются по левому краю.

## Принципы

1. **Проверка адреса — это и есть первый экран.** Не обещание сервиса, а поле ввода,
   которое сразу отвечает. Герой страницы — действие, а не заголовок.
2. **Цвет несёт смысл.** Левая кромка строки окрашена по типу ресурса; авария отличается
   не иконкой, а кирпичной кромкой и словом «аварийное».
3. **Вертикальная линия времени.** Отключения выстроены по одной оси сверху вниз — это
   читается как график работ, а не как лента карточек.
4. **Движение — только в ответ на действие.** Результат проверки появляется один раз,
   мягко. Никаких анимаций при прокрутке и на каждой карточке.
5. **Пустой экран — это приглашение.** «По вашему адресу отключений нет» — законченный
   ответ, а не заглушка.

## Что сознательно не используется

Тёплый кремовый фон с терракотовым акцентом, одинаковые скруглённые карточки с мягкой
серой тенью, градиентные заливки, набранные капслоком надстрочные метки, стрелки в
подписях кнопок. Это сегодняшние умолчания, по ним страницу сразу опознают как
сгенерированную.
