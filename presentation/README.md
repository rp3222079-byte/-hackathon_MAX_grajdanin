# Презентация

- `Domovoy_presentation.pdf` — презентация для сдачи (16 слайдов, первый — служебный).
- `presentation.html` — исходник. PDF собирается печатью в Chrome:

```bash
chrome --headless --no-pdf-header-footer --print-to-pdf=Domovoy_presentation.pdf presentation.html
```

Перед сдачей впишите на первый слайд ссылку на бота, commit hash и токен, а на второй — состав команды (жёлтые поля).
